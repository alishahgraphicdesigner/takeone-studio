# UX Audit — Truth + Reassurance (2026-10-15)

Ali's principle: "har cheez user ko smajh ani chahiye, user panic nai hona chahiye."
Every string below was checked against: "Will the user understand? Will they panic?"

## P0 — Panic risk (user may think data is lost or app is broken)

1. **"Installation did not finish."** (models.js)
   - Problem: Blunt. No reason, no reassurance, no next step.
   - Fix: "The install stopped before finishing — nothing was half-installed. Check your connection and try again; it will start clean."

2. **"Could not delete." / "Could not restore."** (library.js, 4 sites)
   - Problem: User may panic that their project is gone or stuck.
   - Fix: "Couldn't delete — your files are untouched. Try again."

3. **"Failed" badge** (models.js)
   - Problem: Red badge, no explanation inline.
   - Fix: Keep badge, but the error line must say WHY and that retry is safe.

4. **"Installing…" with no progress** (pip installs, dock)
   - Problem: 10-20 min of silence. User assumes it's stuck/broken.
   - Fix: Show what's happening: "Installing… (downloading large files, this takes a while — it's working)."

## P1 — Confusion risk (user doesn't know what to do)

5. **"Could not check."** (verify, models.js)
   - Problem: What does this mean? Is the file broken?
   - Fix: "Couldn't check the file right now — try again. Your files are untouched."

6. **"Could not load the tool catalog."** (models.js)
   - Problem: Technical, no guidance.
   - Fix: "Couldn't load the tool list — check your connection and reopen Models."

7. **"UNTESTED ON THIS PC" badge**
   - Problem: Honest, but does the user know what it means? Sounds alarming.
   - Fix: Add tooltip/title: "This tool hasn't been tried on your PC yet — it should work, but report issues."

8. **"stalled?"** (dock speed)
   - Problem: Question mark causes anxiety.
   - Fix: "Paused — no data right now. The engine retries automatically."

## P2 — Polish (understandable but cold)

9. **"Could not create the project."** → "Couldn't create the project — try again. Nothing was lost."
10. **"Import failed."** → "Couldn't import — the file wasn't changed. Try again."
11. **Queue limit invisibility** — "3 at a time" should be visible on Models page.

## Rule for all future strings
Every user-facing string must answer three questions:
1. What happened? (truth)
2. Why / what does it mean? (reason)
3. What do I do now? (guidance)
And must not cause panic: no bare "Failed", no silent dead ends, no unexplained jargon.
